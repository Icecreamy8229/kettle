## What is this?
Kettle is meant to be a mock online game distribution store.  Users can purchase games by spending points
- - -

## What powers Kettle?
Kettle is built on a pure python web framework called Flask for its backend.
It is DBMS agnostic, and the underlying database can be swapped out without much change of code.
- - - 
### Run on Windows
You can use the provided start.bat to easily run the project on a windows machine.
It will check and make sure the required packages / modules are installed within the virtual environment.
